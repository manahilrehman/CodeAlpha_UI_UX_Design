## 🛠️ Tasks Completed

### Task 1: Wireframing & Low-Fidelity Design
Created low-fidelity wireframes using Figma focusing on layout structure, visual hierarchy, and user navigation for key mobile app screens (Catalog, Progress, Live Sessions, Chat, etc.).

### Task 2: High-Fidelity UI Design
Converted low-fidelity wireframes into clean, polished UI designs with dark/light themes, modern typography, consistent color palettes, icons, and interactive components.

### Task 3: UX Case Study
Conducted a comprehensive UX audit and user journey analysis of online learning platforms, identifying pain points, user flow friction, and proposing 3 targeted design improvements.
* Full Case Study Report available in `UX_Case_Study.pdf` in this repository.

### Task 4: Clickable Prototype Design
Designed an interactive prototype in Figma demonstrating seamless navigation from onboarding to course enrollment, live sessions, and instructor chat.
